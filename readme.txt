MEATCORE ISSUES/BUGS REPO

Post any issue with meatcores here.

Go to ‘Issues’ up the top
‘New issue’
‘Add a title’ –> Game name eg ‘I, Robot’


‘Add a description’ → Describe the issue and include this section:

Screen: TV / CRT
Connection: DV / HDMI / Analog
Mister: Mister / Mister Pi / superstation one / etc


Examples: 


‘The View button in I, Robot is not working/not usable

Screen: CRT
Connection: Analog
Mister: Mister Pi’


‘At the start of level 1 when the truck comes the screen flickers

Screen: TV
Connection: HDMI
Mister: Mister’
